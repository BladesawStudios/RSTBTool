# RESTBL Calculator

Builds the resource size table a mod needs for *Tears of the Kingdom*, *Ocarina of Time* (Switch 2) or *Breath of the Wild*
(Switch and Wii U).


## Build

```bash
git submodule update --init --recursive
dotnet build RestblCalculator.slnx -c Release
```
